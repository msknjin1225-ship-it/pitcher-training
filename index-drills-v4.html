4. あなたのフォーム改善ポイント

① 右股関節で作る

脚を上げた後、右膝を深く曲げることよりも、右股関節に荷重を残したまま右尻から捕手方向へ進む。上体だけを先に倒さない。

合言葉：右尻で進む

② 左脚で受けて、前進を回転へ変える

前足接地後に身体全体がそのまま前へ流れ続けないよう、左股関節で受ける。左膝を無理に突っ張るのではなく、左尻が後ろへ引ける感覚を優先。

合言葉：左尻で止める

③ 骨盤が先、胸郭は後

「胸を閉じる」こと自体を目的にしない。右股関節で進み、左脚で受けることで骨盤が先行し、その後に胸が出る順序を作る。

合言葉：胸は後から出る

④ グラブ側：左手のひらが上を向いて力が抜ける感覚

手のひらが上を向くこと自体を単独で「悪い」とは判定しません。 重要なのは、前足接地後に左肘・左肩まで一緒に落ちたり外へ逃げたりして、左肩が早く開く／胸郭が一気に回る動きとセットになっているかです。

長年無意識に出るなら、手首だけを直そうとするより、グラブ側の上腕・肩甲骨・胸郭の位置を安定させる方が再現性を作りやすいです。

前足接地 → グラブ側を一瞬安定 → 左脚で受ける → 骨盤回転 → 胸がグラブ側へ入る → 腕が走る
NG意識：「左手のひらを下にし続ける」「グラブを強く引く」
推奨意識：「グラブをその場に置き、胸がそこへ入る」

5. 投球ドリル4段階

Rocker → Step-behind → Lead-leg Block → Crow-hop
右股関節で作る → 前へ運ぶ → 左脚で受ける → 骨盤が先行 → 胸が遅れて出る → グラブ側が安定 → 腕が走る、を段階的に投球へつなげます。各カードをタップすると、やり方・回数・画像・動画を確認できます。

① Rocker Drill｜右尻で進む

まずは助走なしで、後脚股関節に乗った力を捕手方向へ運ぶ感覚を作る。胸を無理に閉じず、右尻が先に進む。

狙い：右股関節 → 前進

② Step-behind Throw｜骨盤が先、胸は後

動きを加えても上体が先に開かない順序を作る。後脚股関節に荷重したまま骨盤を運び、胸郭は後からついてくる。

狙い：前進 → 骨盤先行 → 胸郭の遅れ

③ Lead-leg Block Drill｜左尻で止める

前足接地後の前進を左股関節で受け、回転へ変える。左膝を無理に突っ張らず、左尻が後ろへ引ける感覚を優先する。

狙い：左脚で受ける → 骨盤回転

④ Crow-hop Throw｜全身を一つにつなぐ

下半身で作った勢いを、左脚のブロックから胸・腕へ伝える。グラブを強く引かず、その場に置いて胸が入る感覚も確認する。

狙い：下半身 → 体幹 → グラブ側安定 → 腕
右尻で進む → 左尻で止める → 骨盤が回る → 胸が後から出る → グラブ側が安定 → 腕が走る
毎日の痛みルール
鋭い痛み、夜間痛、力が抜ける感じ、投球後も増悪する痛みがある日は投球と高負荷を中止。肩の奥の張りが強い日は「回復・モビリティ」に置き換える。痛みが続く場合は整形外科・スポーツ理学療法士などで評価を。
